Tahapan instalasi Monitoring Proxmox menggunakan telegram

1. instal docker di server linux(ubuntu/debian)
2. masukan folder lalu exstrak zipnya
3. ubah bagian .env.docker (sesuaikan dengan server)
4. server.json(di isi api dari proxmox caranya di DATACENTER Permission > api > create)


   Setelah selesai semua build Docker compose up -d --build

cara menggunakan /status
